# Room For Improvement
Visualise your design before you realise it.


Room For Improvement is an interactive, customisable method for virtual interior design. Users can set the dimensions of the virtual room to exactly match their own, and import furniture from IKEA to test if it would fit in the space and if it would match the aesthetic they are looking for.
